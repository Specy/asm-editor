# Personas

One line per persona, regenerated from frontmatter whenever a persona is saved. Read this first; open a persona's `PERSONA.md` only when casting it or deciding whether to.

- [assembly-instructor](assembly-instructor/PERSONA.md): An assembly instructor discovering ASM Editor and evaluating it for teaching. Interested in: MARS and RARS entry-point guides; app introductions and classroom use cases; shared examples, exercises, test cases, embeds, and exams.
- [assembly-newcomer](assembly-newcomer/PERSONA.md): A student encountering assembly and ASM Editor for the first time. Interested in: getting-started guides and feature walkthroughs; beginner app use cases with runnable examples.
- [curious-web-developer](curious-web-developer/PERSONA.md): A web developer exploring how ASM Editor runs programs in the browser. Interested in: articles about how ASM Editor is built; the connection between browser UI and program execution; browser runtime, compilation, and debugging explanations.
- [lecture-exposed-student](lecture-exposed-student/PERSONA.md): A student with some assembly lecture exposure who is discovering ASM Editor. Interested in: MARS and RARS entry-point guides; turning lecture examples into runnable programs; app setup, stepping, and understanding visible results.
- [reverse-engineering-learner](reverse-engineering-learner/PERSONA.md): A programming learner exploring small x86 executables in ASM Editor. Interested in: beginner reverse-engineering and cybersecurity use cases; x86 executable walkthroughs; understanding branches, input checks, and program state.
