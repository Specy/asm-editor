# Cleanup results — 2026-10-05

The user authorized implementation after the GPT-6 Luna research pass. Changes were made against `bda4250` (`fmt`), which includes the earlier x86 compilation work and pins `@specy/x86` to 4.0.0. Emulator package versions were not changed by this cleanup.

## ProjectSourceSession

`ProjectSourceSession` was a temporary, source-only session for Targets that had not yet acquired a semantic analysis Worker. It registered a live Project's Files and immutable Build snapshots so Monaco could resolve their source URIs, but supplied no diagnostics or symbols. `ProjectLanguageSession` now implements that source lifecycle and connects every supported Target to its analysis Worker. There were no callers of the old class, so it was removed (E01).

## Validation

- `npm run check`: passed, zero errors; 31 warnings remain.
- `npm run lint`: passed.
- Targeted tests: 12 files, 158 tests passed.
- `npm run build`: passed, including prerender and static-site generation. Build warnings remain.
- Production Chromium checks: all five instruction pages loaded their Monaco editors; course index → overview → lecture navigation retained the same document, and direct lecture loading worked. Text/password/number inputs produced the expected exam payload, clearing the number selected unlimited time, and project creation persisted its name and loaded the Workbench editor. No browser page errors were recorded.
- Initial full suite: 116 of 117 files and 2,740 of 2,742 tests passed. Two unchanged whole-corpus lecture-section checks exceeded the five-second limit under the default concurrency. All seven tests in that file passed in a single-worker rerun. `npm test -- --maxWorkers=2` then passed all 117 files and all 2,742 tests. Test timeout settings and runner configuration were not changed.

## Retained and deferred

Persisted-data migrations, source/archive import compatibility, older project/exam link readers, legacy linked-source write-back, preference and shortcut migration, Monaco overflow-hover handling, icon sizing, test-start repaint yields, and editor/connector layout scheduling remain. Their current purpose is documented in the original reports.

The x86 instructions-per-millisecond estimate (E10) and font-family naming were initially deferred. Both are now implemented and validated in the [follow-up results](followup-results.md), with browser measurements and rendered-font evidence. This cleanup makes no claim to remove every future maintenance candidate.
