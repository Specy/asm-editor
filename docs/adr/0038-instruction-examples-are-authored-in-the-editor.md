# Instruction examples are authored in the editor

Each instruction's Documentation entry can carry editor-owned content: a focused runnable
program with its explicit Target and presentation, and optional authored Markdown. We keep
the Core's supported forms and existing descriptions as their authority, but author programs
as ordinary assembly files because syntax samples omit the setup and observable results a
learner needs; generating runnable examples from the first operand form would preserve those
teaching gaps. Pages, the Workbench's Documentation panel and search consume the same authored
supplement, with all machine-state setup in the source so copying a program needs no hidden
configuration.
