# Notes play on the bank MARS plays on JDK 21

The **Audio** Peripheral synthesizes with [spessasynth_lib](https://github.com/spessasus/spessasynth_lib) (Apache-2.0) and the **Emergency GM sound set** that Java's Gervill synthesizer generates when no soundbank is installed, which is the case on JDK 21. [ADR 0035](./0035-environments-match-their-reference.md) takes MARS and RARS as they run on JDK 21, so this bank is what their MIDI services actually sound like there: a student comparing a program with real MARS hears the same instruments. One engine and one bank serve every **Note**, from MARS, RARS and the Z80's audio ports, and the MIDI Files EASy68K's DirectX tasks play.

The bank is `soundbank-emg.sf2`: 128 General MIDI instruments and a drum kit, 1,878,120 bytes, 1.4 MB gzipped, generated by `com.sun.media.sound.EmergencySoundbank`. The generator takes the phases of its FFT-built samples from an unseeded `Math.random()`, so every JVM start makes a slightly different file with the same spectra, and MARS itself plays a bank that differs in those phases each time it starts, which nobody hears. `packages/asm-editor/scripts/audio-bank/generate.mjs` seeds the generator behind `Math.random()` with 0 before running it, so the committed file is reproducible: sha256 `8f9e2d08…0f88a8` on Temurin 21.0.12.1+1, x86_64, the same across runs and JIT modes (corrected on 2026-10-23 while implementing; this paragraph first said the generator's seeds were fixed, which holds only for a few of its instruments). It lives beside the Audio code with a notice naming the OpenJDK file and version that generated it, is imported as a content-hashed asset, and is loaded at runtime the way a font is, never compiled into the bundle.

## Licence

`EmergencySoundbank.java` is OpenJDK code under GPLv2 only with the Classpath Exception, which is incompatible with this repository's AGPLv3 in a combined work. The bank is that program's output rather than its code, and a data file loaded at runtime is aggregated with the editor rather than combined with it, so neither licence reaches the other. The owner accepted this on 2026-10-23. Porting the generator to run in the browser was not an option: that port would be a derivative of the GPLv2-only code itself.

## Considered options

- **GeneralUser GS** through the same engine: a permissively licensed General MIDI bank that sounds much better, 32 MB as SF2 and a few MB as SF3, but not what MARS sounds like. It remains the fallback should the licence position above ever fail.
- **An oscillator synthesizer of our own:** no asset and no licence question, but 128 instruments that all sound like variants of a beep, and poor MIDI Files.

## Consequences

- EASy68K played MIDI Files through Microsoft's GS synthesizer on Windows, whose bank is proprietary, so they sound different here whichever bank is chosen; the owner accepted the difference. EASy68K's WAV Sounds are unaffected, since they are decoded, not synthesized.
- The bank costs nothing until a program first plays a Note or a MIDI File; how a Note asked for before it has loaded behaves is a separate decision in the [design record](../design/audio.md).
- Replacing the bank later changes only the data file and its notice: the engine reads any SF2 or SF3.
