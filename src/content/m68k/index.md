This course is about one machine, the Motorola 68000, and about writing programs for it in the editor
you are reading this in.

If you have never written assembly before, read
[Assembly basics](/learn/courses/assembly-basics) first. It covers registers, memory, branching, the
stack and the rest once and quickly, using whichever language made each point clearest. This course
takes all of that for granted and walks the same ground again slowly, in M68K only.

The last module is **Examples**: complete programs, in the order you can read them. Each one says
what it does, names the lectures it builds on and points out what is new in it, so you can start at
the top and work down, or jump to the one that looks like the thing you are trying to write and
follow it backwards. The same ladder exists in every language course, program for program, so the
M68K bubble sort and the RISC-V bubble sort are the same program written twice.
