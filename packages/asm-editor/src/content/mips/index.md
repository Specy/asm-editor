This course is about one architecture, MIPS, and about writing programs for it.

If you have never written assembly before, read
[Assembly basics](/learn/courses/assembly-basics) first. It is a short tour of the ideas every
assembly language is built on: what a register is, what memory is, how a program branches and how it
keeps a stack. This course assumes you have those and goes back over the same ground slowly, in MIPS.
