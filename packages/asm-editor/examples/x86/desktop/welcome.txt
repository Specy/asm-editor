Welcome to asmOS!

asmOS is a small desktop that runs as one Linux program on the
emulated x86 machine. Everything on the Screen is drawn by the
program itself, into the framebuffer /dev/fb0.

Click the Screen first, so that it gets the keyboard and the mouse.
Shift+Tab gives the keyboard back to the page.

Things to try:
 - Double-click an icon on the desktop, or use the Start menu.
 - Drag a window by its title bar. The taskbar switches windows.
 - Edit this file and press Ctrl+S: the File in the Project changes.
 - Open the Terminal and type help.
 - Open pictures/sunset.bmp from Files, paint on it and Save.
 - Win a game of Minesweeper.
 - Shut Down from the Start menu ends the program.
